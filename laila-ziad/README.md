## التعديل
كل حاجة (الأسماء، الساعة، النصوص، رقم الواتساب، اللوكيشن، الألوان) في ملف واحد: `js/config.js`
الصور في فولدر `images/` (hero.jpg = الصورة الكبيرة، photo2-4 = المعرض).

## الرفع على GitHub
1. اعمل Repository Public جديد.
2. ارفع كل الملفات (Add file → Upload files) — `index.html` لازم يبقى على أول الـ Repository.
3. Settings → Pages → Branch: `main` / root → Save.
4. الرابط: `https://USERNAME.github.io/REPO-NAME/`
